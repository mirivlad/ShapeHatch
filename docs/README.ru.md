# ShapeHatch — генератор моделей для 3D-печати

Создание брелка по изображению или многоцветной плашки с надписью. Реальный размер в миллиметрах, 3D-просмотр, экспорт STL/3MF.

## Установка

```bash
git clone https://github.com/mirivlad/ShapeHatch
cd ShapeHatch
docker compose up -d --build
```

Открывайте **http://192.168.1.54:8086** с любого устройства в домашней сети (адрес tomas). Docker публикует порт 8086 на всех интерфейсах хоста. Для доступа из интернета отдельно настройте HTTPS reverse proxy и необходимые ограничения доступа.

## Генераторы

**Силуэты:** импорт PNG/JPG/WebP/SVG, распознавание фона, внутренние отверстия, сглаживание, ширина, толщина и плоская петелька с отверстием под кольцо.

**Надписи:** пять форм основы; шрифты DejaVu с кириллицей; размер, глубина, цвет; выпуклый текст, гравировка и цветная вставка.

**Просмотр:** мышью вращать, масштабировать и сдвигать; кнопки видов и навигационный кубик.

**Экспорт:** 3MF с отдельными цветными частями (назначьте пластики в слайсере), простой STL и ZIP с отдельными STL, импортируемыми как составной объект.

## Галерея

Первая версия использует **локальную** IndexedDB. Исходная картинка и все настройки хранятся в браузере. Нет пока синхронизации и публичной галереи. Очистка данных сайта удаляет проекты.

## Ограничения

- Не гарантирована печатаемость при любом размере: слишком тонкие элементы могут сломаться.
- Перемещение надписей задаётся X/Y в миллиметрах. Несколько текстовых блоков и перетаскивание на сцене — следующий этап.
- Цвета в 3MF должны быть назначены филаментам в слайсере. Проверка реальными слайсерами и печатью — следующий этап.
- SVG с внешними ресурсами и скриптами отклоняются.
