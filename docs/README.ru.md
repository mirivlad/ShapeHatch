# ShapeHatch — генератор моделей для 3D-печати

Создание брелка по изображению или многоцветной плашки с надписью. Реальный размер в миллиметрах, 3D-просмотр, экспорт STL/3MF.

## Установка

```bash
git clone https://github.com/mirivlad/ShapeHatch
cd ShapeHatch
docker compose up -d --build
```

На компьютере, где запущен Docker Compose, откройте **http://localhost:8086**. Для доступа с другого устройства локальной сети используйте **http://SERVER_IP:8086**, подставив IP-адрес своего сервера. По умолчанию порт 8086 публикуется на всех интерфейсах. Ограничьте доступ брандмауэром или привяжите порт к localhost, а перед публикацией в интернете настройте HTTPS и контроль доступа.

## Генераторы

**Силуэты:** импорт PNG/JPG/WebP/SVG, распознавание фона, внутренние отверстия, сглаживание, ширина, толщина, плоская петелька или выступающий из края закруглённый столбик с поперечным отверстием.

**Надписи:** пять форм основы; 12 шрифтов с кириллицей: DejaVu (4 варианта), Russo One, Play Bold, PT Sans, Lobster, Rubik Mono One, Unbounded, Comfortaa, Terminus TTF; многострочный текст, размер, глубина, цвет; выпуклый текст, гравировка и цветная вставка; сквозное отверстие, плоская петелька или столбик с поперечным отверстием.

**Просмотр:** мышью вращать, масштабировать и сдвигать; кнопки видов и навигационный кубик. Когда включено крепление, перетащите бирюзовую точку по 3D-сцене: она автоматически прилипает к ближайшей точке внешнего контура. Можно также точно задать положение ползунком. На изображениях с несколькими отдельными фрагментами используется контур самого большого фрагмента. Для табличек оранжевая ручка в середине текстовой области позволяет перемещать надпись по плоскости (X/Y в миллиметрах). Если текст не помещается, экспорт блокируется до исправления параметров.

**Экспорт:** 3MF с отдельными цветными частями (назначьте пластики в слайсере), простой STL и ZIP с отдельными STL, импортируемыми как составной объект.

## Настройки редактора

Разделы «Основа», «Крепление», «Надпись» (для силуэтов — «Изображение», «Размеры», «Петелька») оформлены аккордеонами: при открытии редактора развёрнут только первый раздел. Размеры отверстия и стенки крепления сохраняются в localStorage браузера и автоматически подставляются в новые проекты обоих генераторов. Настройки уже сохранённых проектов остаются независимыми.

Восемь новых TTF-файлов распространяются по лицензии SIL OFL 1.1. Источники и копии лицензий приведены в [списке шрифтов](../backend/fonts/README.md). Перед печатью особенно проверяйте мелкие штрихи шрифта Terminus.

## Галерея

Первая версия использует **локальную** IndexedDB. Исходная картинка и все настройки хранятся в браузере. Нет пока синхронизации и публичной галереи. Очистка данных сайта удаляет проекты.

## Толщина изделия и крепление

При выборе столбика с поперечным отверстием толщина брелка или таблички автоматически подгоняется под его наружный диаметр: **диаметр отверстия + 2 × толщина стенки**. Столбик выходит из края модели, отверстие смотрит вбок, а не в сторону лицевой поверхности. При смене режима обычное значение толщины сохраняется. Проверьте модель в слайсере и убедитесь, что выбранная толщина подходит для изделия.

## Ограничения

- Не гарантирована печатаемость при любом размере: слишком тонкие элементы могут сломаться.
- Положение текста можно менять мышью на сцене или вручную через X/Y в миллиметрах. Несколько независимых текстовых блоков пока не поддерживаются.
- Цвета в 3MF должны быть назначены филаментам в слайсере. Проверка реальными слайсерами и печатью — следующий этап.
- SVG с внешними ресурсами и скриптами отклоняются.
